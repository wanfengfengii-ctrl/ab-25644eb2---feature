纸本修复室 · 雾化管路配平

回湿脆化古画前，审核雾化管路能否把规定水量稳定送到每个分区：水源总量精确流出、分流节点收支相等、分区精确满足需求、各管流量落在最小/最大量内；先最小化相对优选量的绝对偏差和，再按管路录入顺序稳定决胜。还可在同一草稿上叠加 2~4 个连续雾化时隙做时序复核：逐隙水源放出、分区逐隙需求、管路行程时隙与节点暂存上限一并求解，避免行程与暂存被静态配平掩盖。

时序复核（2 ~ 4 个连续雾化时隙）

在上方管路草稿旁叠加时隙维度：填写各时隙水源放水量、分区逐隙精确需求、每条管路的整数行程时隙与每个分流节点的暂存上限。 时隙 t 发出的水量于时隙 t+行程 到达下游；任一管路各时隙发出量仍落在最小/最大量内，节点逐隙库存不超过暂存上限； 每时隙水源放出恰等于申报量、分区到水恰等于该隙需求，期末不留库存与在途水量。 可行时先最小化各（时隙×管路）发出量相对优选量的总绝对偏差，再按时隙与管路录入顺序稳定决胜。

时隙编号 0 起；行程时隙 0 表示当期到达。期末之后才能到达的时隙发出量恒为 0，这些时隙若最小量大于 0 则与"期末无在途"冲突、整案不可行
